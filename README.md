# Seans – lista filmów i seriali
Appka webowa (PWA). Wyszukujesz tytuł, czytasz opis, sprawdzasz, na jakiej platformie jest dostępny i dodajesz go do swojej listy.

## Pobierz klucz TMDB
1. Wejdź na https://www.themoviedb.org/signup i załóż konto. Potwierdź adres e-mail.
2. Zaloguj się i otwórz https://www.themoviedb.org/settings/api
3. Kliknij **Create** / **Request an API key** i wybierz **Developer** (użytek prywatny).
4. Skopiuj **API** 

## Krok 3: instalacja
1. Otwórz adres z kroku 2 w **Safari**.
2. Stuknij **Udostępnij** → **Dodaj do ekranu początkowego** → **Dodaj**.
3. Uruchom appkę **z ikony na ekranie** i wklej klucz **TMDB**.
